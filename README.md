# RiSaber

Делаю лендинги, сайты-визитки и веб-приложения для людей и небольшого бизнеса.

## Услуги

- Лендинги
- Сайты-визитки
- Веб-приложения

## Демо-проекты

Это демонстрационные проекты на вымышленных данных, а не работы для клиентов.

- [AutoProject](https://github.com/RiSaber/AutoProject): лендинг автосервиса «АвтоМастер» с услугами, отзывами и онлайн-записью. [Открыть сайт](https://risaber.github.io/AutoProject/)
- [inventory-manager](https://github.com/RiSaber/inventory-manager): веб-приложение для учёта товаров небольшого магазина на Python, FastAPI и SQLite: остатки, поступления, продажи, история и статистика.
