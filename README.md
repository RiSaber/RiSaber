# RiSaber

Делаю сайты, веб-приложения и Telegram-ботов для людей и бизнеса.

## Услуги

- Лендинги и сайты-визитки
- Каталоги и интернет-магазины
- Веб-приложения: учёт, формы, панели со статистикой
- Telegram-боты
- Доработка и правки существующих сайтов

## Демо-проекты

Это демонстрационные проекты на вымышленных данных, а не работы для клиентов.

- [AutoProject](https://github.com/RiSaber/AutoProject): лендинг автосервиса «АвтоМастер» с услугами, отзывами и онлайн-записью. [Открыть сайт](https://risaber.github.io/AutoProject/)
- [inventory-manager](https://github.com/RiSaber/inventory-manager): приложение для учёта товаров небольшого магазина на Python, FastAPI и SQLite: остатки, поступления, продажи, история и статистика.
